# Світ 3D-технологій — тема №11

Готовий багатосторінковий навчальний вебсайт на HTML, CSS та JavaScript.

## Структура
- `index.html` — головна сторінка (рівень 1)
- `basics.html`, `applications.html`, `software.html`, `future.html` — чотири сторінки другого рівня
- інші HTML-файли — підсторінки третього рівня
- `css/style.css` — оформлення
- `js/main.js` — мобільне меню та активний пункт навігації

## Запуск локально
Відкрийте `index.html` у браузері. Для зручної роботи можна відкрити папку у Visual Studio Code.

## Публікація на GitHub Pages
1. Створіть репозиторій на GitHub, наприклад `3d-technologies`.
2. Завантажте в репозиторій усі файли й папки з цього архіву (саме в корінь репозиторію).
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**.
5. Виберіть гілку `main` і папку `/ (root)`, натисніть **Save**.
6. Дочекайтеся публікації. Адреса матиме вигляд `https://ВАШ_ЛОГІН.github.io/3d-technologies/`.
